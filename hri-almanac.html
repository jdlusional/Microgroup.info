Almanac

Almanac is a funding-prospect tool built for Human Rights Initiative of North Texas (hrionline.org), matching HRI's immigration and human-rights legal-aid mission against public IRS grant-filing data.

This engagement (Almanac + Scribe Pro) is provided to Human Rights Initiative of North Texas as a 90-day in-kind donation.
Every funder listed here traces to a public source (HRI's own site, IRS Form 990 data via ProPublica, or a real grant record in the national Schedule I filing data). Nothing here is estimated or invented. This is a first pipeline pass, not yet a multi-round hand-verified search like Almanac's more mature client builds -- see the methodology note below for exactly what's confirmed and what isn't.

Method

How this was built

TopicWhat it means
Where this comes from Every funder and every grant candidate on this page is drawn from a public record: IRS Form 990 filings (via ProPublica Nonprofit Explorer's JSON API) and the national Schedule I grants-paid dataset.

Each match is a real, dated grant record, not an estimate.

Where a funder does not publish a figure, that gap is marked as unconfirmed rather than filled in.
What Almanac will not do It does not invent a fact about a funder.

It also keeps a hard line between a funder that has actually given to this organization before and a funder that merely looks like a good fit.

A candidate is never dressed up as a confirmed prior funder.
What it cannot tell you This is a first-pass Almanac build for HRI, not yet a multi-round hand-verified search like Almanac's more mature client pages.

No confirmed-prior-funder list is shown: this pass did not independently verify HRI's actual current funding relationships (that would need a direct HRI 990 Schedule I read or an owner-supplied funder list), so nothing is asserted here that isn't backed by a source.

Open-grant-opportunity research (live deadlines, application portals, eligibility detail per funder) has not been run for HRI yet -- this pass covered org-profile confirmation and the Schedule I candidate-funder search only.
How candidates are found and ranked The candidate funders come from one run of Almanac's v2 pipeline (NTEE/geography-weighted, scored token/phrase purpose matching against the national Schedule I grants-paid dataset), scoped to the currently available Texas-only Schedule I extract.

The national extract has not yet been added to this data repository (a known, tracked limitation), so this candidate list under-represents out-of-state immigration/human-rights funders that likely also fund HRI's work.

Every candidate below traces to a real, dated grant record in that dataset; nothing is estimated.
