A Few Questions Before We Build

This is a short set of open questions for you, the owner, about the Clown Dog Bikes rebuild. Some have a bounded set of answers and are multiple choice; the rest are genuinely open, and there's room to write as much or as little as you want.

Why we're asking. A few of these questions came up while reviewing the current clowndogbikes.com site directly: a restocking-fee policy that never states a percentage, some marketing claims we couldn't independently verify, and basic access questions (the domain registrar, the current site's admin backend) that only you can answer.

Most questions below are required. If a question genuinely doesn't apply, write "N/A" rather than leaving it blank. The restocking-fee question and every file upload are optional; the two "who has it" / "which system" follow-ups are only required when the answer that triggers them is selected.

Please read before you submit

Do not send passwords, account numbers, or other sensitive information through this form's text fields or by email. Email is not a secure channel, and anything typed into a text box here is not either.

If something sensitive needs to be shared with us (a login, a financial detail, anything you wouldn't want sitting in an inbox), put it in a document instead and upload it under Domain and Access below. If you're not sure how to do that, say so in the form and we'll walk you through it.
